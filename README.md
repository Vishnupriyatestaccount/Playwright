# Playwright Practice Repository

This repository contains Playwright practice files and JavaScript basics exercises.

## Project structure

- `Chapter_01_Basics/` - basic JavaScript and Playwright examples.
- `Chapter_02_javabasics/` - Java basics exercises.
- `Chapter_03_Identifier_Literals/` - identifier and literal examples.

## Getting started

1. Install Node.js if not already installed.
2. Install project dependencies if you add a `package.json` later.
3. Run Playwright tests with your preferred command, for example:

```bash
npx playwright test
```

## Notes

- `.gitignore` includes Node, Playwright artifacts, editor settings, and environment files.
- This repo currently includes example JS files under `Chapter_01_Basics`.
