# Windows Keyboard Shortcuts

## General shortcuts
- Ctrl + C: Copy
- Ctrl + X: Cut
- Ctrl + V: Paste
- Ctrl + Z: Undo
- Ctrl + Y: Redo
- Ctrl + A: Select all
- Ctrl + S: Save
- Ctrl + P: Print
- Alt + F4: Close active window
- Alt + Tab: Switch apps
- Windows + D: Show desktop
- Windows + E: Open File Explorer
- Windows + L: Lock computer
- Windows + M: Minimize all windows
- Windows + Shift + M: Restore minimized windows
- Windows + R: Open Run dialog
- Windows + I: Open Settings
- Windows + S: Open search
- Windows + X: Open Quick Link menu
- Windows + A: Open Action Center
- Windows + N: Open notification center
- Windows + Tab: Open Task View

## Window management
- Windows + Left Arrow: Snap window to left
- Windows + Right Arrow: Snap window to right
- Windows + Up Arrow: Maximize window
- Windows + Down Arrow: Restore/minimize window
- Windows + Home: Minimize all except active window
- Windows + Shift + Left/Right Arrow: Move window between monitors
- Windows + Shift + Up Arrow: Stretch window vertically
- Windows + Shift + Down Arrow: Restore/maximize window vertically

## File Explorer shortcuts
- F2: Rename selected item
- Ctrl + N: Open new window
- Ctrl + W: Close current window
- Ctrl + Shift + N: Create new folder
- Alt + Enter: Open Properties for selected item
- Alt + Up Arrow: Go up one folder level
- Alt + Left Arrow: Go back
- Alt + Right Arrow: Go forward
- Ctrl + Shift + E: Expand all folders in navigation pane
- Ctrl + Mouse wheel: Change icon size

## Text editing shortcuts
- Ctrl + B: Bold text (in many apps)
- Ctrl + I: Italic text
- Ctrl + U: Underline text
- Ctrl + F: Find
- Ctrl + H: Replace
- Ctrl + K: Insert hyperlink (in some apps)
- Ctrl + Shift + Left/Right Arrow: Select one word at a time
- Ctrl + Home: Go to beginning of document
- Ctrl + End: Go to end of document
- Shift + Home/End: Select to beginning/end of line

## Accessibility shortcuts
- Windows + Plus (+): Zoom in with Magnifier
- Windows + Minus (-): Zoom out with Magnifier
- Windows + Esc: Exit Magnifier
- Windows + Enter: Open Narrator
- Windows + U: Open Accessibility settings

## Screenshots
- PrtScn: Copy entire screen to clipboard
- Alt + PrtScn: Copy active window to clipboard
- Windows + PrtScn: Capture entire screen to file
- Windows + Shift + S: Open Snipping Tool for screenshot selection

## Virtual desktops
- Windows + Ctrl + D: Create new virtual desktop
- Windows + Ctrl + Left/Right Arrow: Switch virtual desktops
- Windows + Ctrl + F4: Close current virtual desktop

## Power user shortcuts
- Ctrl + Shift + Esc: Open Task Manager
- Windows + Pause: Open System Properties
- Windows + Ctrl + N: Open Narrator Quick Start
- Windows + P: Project display settings
- Windows + B: Focus system tray
